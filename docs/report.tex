\section{Plan}
The approach follows what worked for imperfect-information games at scale
(Pluribus/ReBeL for poker, DeepNash for Stratego, NooK for Bridge):
imitate humans first, then improve by self-play, and add search over hidden cards at play time.

\section{Rules and encoding}
Encoding matches HSLU \texttt{jass-kit} so data and agents are interchangeable. Seats play counter-clockwise
($\mathrm{next}(p) = p+3 \bmod 4$), teams are $\{0,2\}$ and $\{1,3\}$. A hand is a 36-bit set in one \texttt{uint64}.

Implemented: follow suit; trumping in is always allowed; no under-trumping unless only trumps are left;
the Puur (trump J) never has to be played; push to partner.
\textbf{Not yet:} Weis, St\"ock, trump multipliers (P1). The Swisslos logs contain none of these either.

\begin{itemize}
\item Bitboard hands; legal moves in a few bit operations.
\item \SingleHeuristic{} rounds/s on one thread, \PeakHeuristic{} with all \Cores{} (heuristic agents).
  Only 2 of the cores are performance cores, so scaling is sub-linear.
\item Laptop numbers depend on turbo and power limits (best of 3 shown). Long runs at $\approx$100\,$^\circ$C
  vary by up to $\pm$25\,\%. The monitor shows frequency and temperature next to the rate.
\item Duplicate deals: each deal is played twice with seats swapped, which cancels most card luck.
\item \texttt{VecEnv} C API: $N$ rounds stepped in one call, with numpy views for learning agents.
\end{itemize}

\subsection*{Validation}
\begin{tabular}{@{}lr@{}}
\toprule
Check & Result \\ \midrule
Swisslos games replayed (every card legal, winners and points exact) & \NReplayOK{} / \NGames \\
Legal moves vs.\ HSLU \texttt{jass-kit}, 119\,073 random states & 173 differ, all jass-kit bug$^\ast$ \\
Trick winners vs.\ \texttt{jass-kit}, 20\,000 random tricks & identical \\
Heuristic vs.\ random (2\,M duplicate deals, points/round, 95\,\% CI) & \HeurDiff{}, win rate \HeurWin \\
Random vs.\ random / heuristic vs.\ heuristic & $\approx 0$ (sanity) \\
\bottomrule
\end{tabular}

{\footnotesize $^\ast$\,With two trumps already in a trick, \texttt{jass-kit} takes the one with the larger
card index as highest instead of the higher trump rank, and then allows under-trumping. None of the
human games hit this case (the Swisslos server enforces the rule), so it only affects bots trained with jass-kit.}
